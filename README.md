# Нефрит — маджонг-пасьянс

Мобильная PWA: TypeScript + Vite + SVG, сохранение через IndexedDB (`idb`).
Оригинальные SVG-костяшки Postmodern из GNOME Mahjongg и раскладка «Черепаха» на 144 костяшки.
Независимый проект под GPL-3.0-or-later; сведения об авторах — в NOTICE.md.

## Локальный запуск

Нужны Node.js 24 и npm; Git и GNU tar для работы с исходниками и упаковки.

```bash
nvm use
npm ci
npm run dev
```

Откройте адрес Local из терминала (обычно http://localhost:5173).
Остановить сервер: **Ctrl+C** в том же терминале. Для повторного запуска выполните
`npm run dev` из каталога игры; повторная установка зависимостей не нужна.
Закрытие вкладки браузера не останавливает сервер. Кнопка паузы в игре останавливает
игровые часы, но не сервер. Для постоянного адреса можно использовать
`npm run dev -- --port 5173 --strictPort`.
Чтобы проверить на Android, подключите телефон к той же Wi-Fi сети и откройте
адрес Network из терминала. Если доступ блокирует firewall, разрешите порт
локального сервера только для своей домашней сети.

В режиме разработки service worker отключён. По обычному HTTP через LAN можно
проверить игру и IndexedDB, но для установки PWA и офлайн-кэша на телефоне нужен HTTPS.

## Проверка и сборка

```bash
npm test
npm run build
npm run preview
```

Сборка создаётся в `dist/`. Preview по умолчанию использует порт 4173.
На localhost production-сборка устанавливает service worker: после его активации
повторное открытие работает без сети. Обновление предлагает кнопку «Обновить»;
игра сохраняется до перезагрузки. При разработке не используйте один и тот же
origin/порт для старого production-кэша и dev-сервера. Удалить кэш можно в DevTools
→ Application → Service Workers → Unregister.

## Публикация на Android

Загрузите **содержимое dist/** на статический хостинг с HTTPS: GitHub Pages,
Cloudflare Pages или собственный сервер. Сборка использует относительные пути,
поэтому поддерживает размещение в подпапке. Для `sw.js` рекомендуется
`Cache-Control: no-cache`. Не публикуйте dev-сервер в интернете.

Откройте HTTPS-ссылку на Android в современном Chrome. Дождитесь первого полного
открытия, затем выберите «Установить приложение» в меню или кнопку установки,
если браузер её предлагает. После первого успешного кэширования игра работает офлайн.

Backend, учётные записи, аналитика, внешние шрифты и сетевые изображения отсутствуют.
IndexedDB и кэш привязаны к origin браузера. Другой домен, профиль, установка из
другого браузера или очистка данных сайта не перенесут старую партию автоматически.
Приватный режим/нехватка места могут ограничивать сохранение: приложение покажет предупреждение.

## Что реализовано

- Решаемые раздачи с воспроизводимым seed, 36 видов костяшек по четыре штуки.
- Свободная костяшка: сверху нет перекрытия, хотя бы одна боковая сторона свободна.
- Подсказки, отмена/повтор, перемешивание оставшегося поля с решением.
- Пауза с закрытым полем; часы останавливаются в меню и в фоновой вкладке.
- Сохранение после каждого хода, изменения настроек и каждые 10 секунд игры.
- Продолжение партии, таймер, настройка подсветки свободных костяшек.
- Локальная статистика побед и лучшего времени (включая подсказки/перемешивания).
- Список рекордов по времени, дата победы, подсказки и перемешивания; импорт history GNOME.
- Масштаб, жесты двумя пальцами, перемещение поля; Tab/Enter и Ctrl+Z.
- Выбор мышью сразу при нажатии, без ожидания остановки курсора.
- Единый SVG-атлас для одновременной загрузки всех рисунков костяшек.
- На телефоне поле занимает всё окно; счётчики и управление открываются кнопкой ☰
  поверх поля и скрываются повторным нажатием или касанием поля.
- Полноэкранный режим (с запасным разворотом в окне браузера), выход по кнопке или Esc.
- Офлайн-кэш, manifest и иконки PWA, архив соответствующих исходников в сборке.

Каждая новая раздача имеет решение, но произвольная последовательность ходов может
привести к тупику. Подсказка показывает доступную пару, а не стратегическое решение.
Перемешивание сохраняет снятые пары; если ограниченный поиск не найдёт полный путь,
поле не изменится — отмените несколько ходов и попробуйте снова.
Для одновременной игры используйте одну вкладку на браузер: общей синхронизации вкладок нет.

## Рекорды и импорт GNOME

Нажмите кубок в верхнем меню. Новые победы автоматически попадают в список;
можно выбрать раскладку и показать следующие 50 записей. Старые общие счётчики
сохраняются, но даты и подробности прежних побед восстановить из них нельзя.

В этом же окне выберите файл `history` оригинальной игры. Обычный путь в Linux:
`~/.local/share/gnome-mahjongg/history` (либо `$XDG_DATA_HOME/gnome-mahjongg/history`).
Для Flatpak обычно: `~/.var/app/org.gnome.Mahjongg/data/gnome-mahjongg/history`.
В диалоге выбора файла можно нажать Ctrl+L и вставить полный путь.

Поддерживаются строки `ISO8601 раскладка секунды` и новый вариант
`ISO8601 раскладка секунды имя игрока`, например:

```text
2026-11-03T12:00:00+01:00 easy 180 Иван Петров
```

Формат проверен по исходникам GNOME `src/history.vala` (ветки main и gnome-3-38).
Историческое имя `easy` распознаётся как «Черепаха».
Импорт объединяет записи, сообщает число добавленных/повторных/неверных строк,
не заменяет текущую партию и не меняет локальные счётчики побед в настройках.
Повторная загрузка одного файла не создаёт дубликатов. Лимиты: 2 МБ и 10 000 строк.
Импортированные раскладки кроме «Черепахи» доступны в таблице, но не для игры.
GNOME не хранит сведения о подсказках/перемешиваниях в history.
Все рекорды локальны: общего рейтинга и синхронизации между устройствами нет.

## GitHub Pages

Готовый workflow: `.github/workflows/pages.yml`. Он проверяет тесты, собирает игру
и публикует `dist/` при push в `main`. Настройки Vite уже поддерживают подпапку репозитория.

1. Создайте пустой публичный репозиторий на GitHub без автоматически созданных файлов.
2. Из каталога игры выполните команды ниже, заменив URL своим. В текущем проекте Git уже инициализирован.

```bash
git add .gitignore .nvmrc .github LICENSE NOTICE.md README.md index.html package.json package-lock.json public scripts src tests tsconfig.json vite.config.ts
git commit -m "Publish Nephrite Mahjongg"
git branch -M main
git remote add origin https://github.com/YOUR_NAME/mahjongg.git
git push -u origin main
```

3. В репозитории откройте Settings → Pages → Build and deployment → Source → **GitHub Actions**.
4. Откройте Actions → Publish game to GitHub Pages → Run workflow, если первый push
   произошёл до включения Pages. После успешной публикации ссылка будет в Settings → Pages:
   `https://YOUR_NAME.github.io/mahjongg/`.

Не загружайте `node_modules`, служебные `.aws`/`.codex`/`.agents` и личные файлы.
Публикуемый архив исходников использует явный список разрешённых файлов.
Локальные сохранения на домен GitHub Pages автоматически не переедут.
Инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

## Структура

- `src/game.ts` — правила, генератор решаемых раздач, проверка сохранений.
- `src/board.ts`, `src/art.ts` — SVG-поле, жесты, обрезка оригинального атласа GNOME Postmodern.
- `src/storage.ts` — транзакции IndexedDB и статистика.
- `src/main.ts`, `src/style.css` — интерфейс и жизненный цикл партии/PWA.
- `scripts/package-source.mjs` — архив соответствующих исходников и service worker.
- `tests/` — игровые правила, решаемость, отмена, перемешивание, IndexedDB.

## Рисунки для художника

`public/themes/postmodern.svg` — неизменённый оригинальный SVG-атлас GNOME Mahjongg;
рядом сохранена его GPL-лицензия. Он содержит 43 столбца по 64×88 единиц и две
строки: обычные костяшки и выделенные синим. Подключение и соответствие рисунков
типам находятся в `src/art.ts`. Размер лицевой стороны — 56×80, смещение слоя —
8×8; эти пропорции и порядок отрисовки повторяют GNOME. При замене графики
сохраняйте эту структуру атласа либо измените размеры/соответствия в `src/art.ts`.
Четыре цветка и четыре времени года имеют разные рисунки, но совпадают внутри
своей группы, как в оригинальной игре.
